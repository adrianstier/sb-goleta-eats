# Santa Barbara & Goleta Eats

*Last updated: 2026-11-09*

A map-and-list guide to the restaurants, bars, coffee and breakfast spots we recommend around Santa Barbara, the Funk Zone, Montecito and Goleta.

Live site: https://adrianstier.github.io/sb-goleta-eats/

- Places were checked for closures on 2026-11-09 against local news and current listings.
- Pink pins mark new (2024–2026) places getting a lot of local and national coverage.
- Map data © OpenStreetMap contributors.

The page is a single static `index.html` with no build step.
